# MS2 완료 기준 공통 경기 규칙 보강 — 2026-09-23

## 범위와 단계

사용자 최신 지시로 기존의 ‘패스를 강제하지 않는다’는 제한을 변경했다. MS2-v2 준비 정책(200,120 step)의 가중치는 보존하고 공통 실행 규칙을 바꾼다. 이번 작업은 MS2 완료 기준의 경기 규칙 보강이며 MS3-v2 재검증으로 연결된다. 새 독립 알파벳 단계를 추가하지 않는다.

MS0/MS1 완료 이력 → MS2-v2 준비(R5) 완료 → MS3-v2 초기(R6, 402,389 step) 및 안정화(D1~D5) 완료 이력은 보존한다. 이번 규칙이 달라졌으므로 이전 D5의 준비 manifest와 Player는 현행 학습 시작 근거로 사용할 수 없다. R7/R8, MS3 전체 완료, 대규모 학습, 신규 optimizer 갱신·모델 승격은 이번 범위가 아니다.

## 적용 계약

- 연속 소유 중 상대 골문 방향 최고 위치를 2초 동안 갱신하지 못하면 동료에게 패스를 시도한다. 물리 흔들림을 제외하기 위해 0.1m 이상 최고 위치 갱신을 전진으로 센다. 이 0.1m 기준은 사용자 후속 응답으로 명시적으로 확정했다. 후퇴했다가 같은 위치로 돌아오는 동작은 타이머를 초기화하지 않는다. 소유 선수 변경·상실·라운드 초기화 시 타이머를 초기화한다.
- 유효한 동료가 있으면 감독의 최신 명령보다 공통 패스 실행을 우선한다. 기존 2초 킥 준비 예산과 수신 예산을 사용한다. 명령 원본은 그대로 기록하고 실행 과제의 공통 규칙 여부를 별도로 기록한다. 기존 권장 패스 거리(5~28m)의 동료를 우선하되, 그 범위에 동료가 없어도 가장 가까운 동료를 향한 패스 시도는 생략하지 않는다. 다른 활성 자동 동료 자체가 없을 때만 대상 없음으로 기록한다. 거리 밖 시도의 성공을 보장하거나 수신을 조작하지 않는다.
- 기존 공통 골문 위험 구역(팀 공격 좌표 깊이 −48m 이하, 골문 반폭+4m 이내)에서는 2초를 기다리지 않고 전방 동료 패스 또는 중앙 방향 강한 킥을 실행한다. 골키퍼·필드 선수 모두 같은 기준이다. 위험 구역 밖의 수비 전술·역할 배치를 일괄 교체하지 않는다.
- MNG의 학습형 감독·규칙형 감독·fallback과 공통 Core의 자동 선수에 적용한다. 수동 조작 선수의 입력 소유권은 유지한다. 보상·관측 차원·행동 차원·모델 파일은 변경하지 않는다. 규칙에 따른 시도만으로 보상하지 않는다.
- 환경 revision은 `MNG-MS2-common-possession-stop-20260923`으로 분리한다. 훈련 실행기는 현행 schema의 revision과 다른 구 Player를 거부한다.

## 판단과 다음 단계

이번 사용자 요구인 공통 강제 시도와 역할에 관계없는 골문 앞 걷어내기를 구현하고 동결 비교했다. 규칙은 유지할 근거가 있으나 **수비 부족 전체 해결, 정책 학습 개선, 새 champion 승격을 선언하지 않는다.** 정체 강제 조건은 실제 경기에서3회로 드물었고, 대부분의 새 행동은 골문 앞 개입이었다. 보유를 잃기 전에 준비를 끝내는 능력과 수신 성공률이 다음 관찰 지점이다. 이번 결과를 근거로 패스 보상을 더 올리거나 감독 전략을 크게 재설계하지 않았다.

## 2026-09-13 학습과 축구 코드의 책임 경계

- 코드가 공의 정확한 위치·방향·속도 조회, 선수별 접근경로, 시야 밖 근거리 공 반응, 패스 수신 위치, 압박 회피 경로, 킥 플레이트 조준·실제 발사, 골키퍼 위치·주시를 안정적으로 수행한다.
- 감독 PPO는 `언제 전진할지, PassBuild를 언제 선택할지, 언제 슛·압박·균형·후방보호로 전환할지`를6개 명령으로 학습한다. 패스 대상과 슛 좌표는 코드가 현재 상황에서 안전도가 높은 후보를 계산한다.
- 명령을 골랐다는 사실은 보상이 아니다. 실제 플레이트 슛 궤적,3m 이상 이동 뒤 다른 동료의0.20초 소유, 소유 사이클 중5m 전진, 회수, 득실점·승패만 학습 신호가 된다.
- 2026-09-20 공통 패스 규칙은 전진 통로가 막히면 후진·횡이동 전에 패스를 검토하고, 수신 선수보다 경기장 중앙 쪽으로1.5m 치우친 lead 지점을 조준한다. R0와 PPO가 같은 Planner/Executor를 사용하며 실제 완료 패스 보상은 `+0.06`이다.
- 목표는 선수의 원시 운동기술 습득이 아니라, 같은 코드 기술과 고정 상대·고정 seed에서 학습 checkpoint가 무작위/초기 정책보다 승률·득점·실점·전술 선택을 개선하는 것을 입증하는 것이다.
- 중요한 Run은 진전이 이어지면100k 이상 진행하되 숫자를 채우는 것이 목적은 아니다. 두 연속 checkpoint 평가에서 성능과 행동분포가 모두 정체하면 저장 후 조기 중단하며, 같은 실패가2회면 새 소규모 버전 대신 전체 관측·mask·보상·실행·상대·평가 설계를 재점검한다.

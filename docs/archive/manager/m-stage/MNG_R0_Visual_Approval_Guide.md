# MNG R0 규칙형 감독 육안 승인 가이드

## 목적

> **2026-09-19 사용자 완료 판정 반영:** 현재 R0의 승인은 완료되었다. 아래 가이드는 승인 당시 확인 항목과 향후 회귀 관전 참고용이며, MS 시작 전에 재승인을 요구하지 않는다. 다음 작업은 [MS 계획](../ms-v1/ms-plan.md)을 따른다.

R0는 강화학습 없이 동일한 규칙형 감독 v0가 Red와 Navy를 각각 지휘하는 기준선이다. 자동 테스트는 기능과 안정성을 확인하고, 사람의 최종 검토는 실제 경기 흐름의 자연스러움을 확인한다.

2026-09-19 Planner v9 자동 승인 버전은 300초 경기 득점, 실제 패스·완료 패스·슈팅 킥, 전진,6개 감독 명령, 팀 간격, 자기 골대 방향 운반 제한과 함께 2인 수비 압박·상대 골문 근처 2인 공격 가담·미드필더 골문 복귀·정체 안전 슈팅 우선을 통과했다. 패스·슛의 힘1000 증가분도 실제 킥 플레이트 물리로 검증했다. 현재 이 버전은 사용자 육안 승인 후보이며 M1은 보류 상태다. 이 문서의 검토는 기능 재시험이 아니라 최종 경기 체감 확인이다.

## 실행

1. Unity에서 `Assets/_Soccer/Manager/Curriculum/R0_RuleBaseline/Scenes/MNG_R0_RuleVsRule.unity`를 연다.
2. Game View를 보이게 하고 Play를 누른다. R0 관전은1배속이며 H키 조작은 비활성이다.
3. 중계 카메라와 HUD에서 Red/Navy의 현재 명령, 점수, 남은 시간을 확인한다.
4. 한 장면만 보고 판정하지 말고 최소 한 경기, 가능하면 킥오프 재개가 포함된 두 경기를 관전한다. 첫 경기가 끝나면 Play를 다시 눌러 새 경기를 시작한다.

## 합격 확인 항목

- 양 팀 네 선수가 모두 움직이며 한 경로로 겹쳐 몰리지 않는다.
- 소유 팀은 전진하고 압박을 받으면 패스하며, 슛 가능 거리에서는 실제 킥 플레이트로 슛을 시도한다.
- 상대 골대30m 안으로 드리블해 들어가면 운반자 외 동료 한 명이 공의 공격 방향·안쪽 측면으로 합류한다. 두 선수가 같은 점에서 서로 밀지 않고 패스 선택지와 리바운드 공격을 만들며, 나머지 선수까지 전부 공에 몰리지는 않는다.
- 상대가 공을 소유하면 비소유 팀의 최소2명이 함께 압박한다. 한 명은 공을 직접 다투고 다른 한 명은 골대 쪽에서 패스·돌파 경로를 막으며, 같은 점에 겹쳐 밀기만 하지 않는다.
- 공이 자기 골대 가까이 왔을 때 상대 진영에 있던 MidLeft/MidRight가 공격 위치에 남지 않고 골문 근처 압박·차단 위치로 복귀한다.
- 골키퍼는 이동 중에도 공을 바라보고 적극적으로 문전을 방어한다.
- 패스·슛·드리블은 공 순간이동이 아니라 킥 플레이트 접촉으로 실행된다.
- 공 경합이 한자리에 정체되면 먼저 상대 골문 방향의 강한 킥을 준비한다. 자기 골대 방향으로 차려 하지 않으며, 첫 킥으로 풀리지 않으면 여러 선수가 서로 다른 각도로 다시 접근한다.
- 골이 나면3초 뒤 중앙 킥오프로 재개되고, `±3.00m` 스폰 변화는 최초 시작과 킥오프에만 적용된다. 경기 중 순간 재배치는 없어야 한다.
- 카메라, HUD, 공, 선수, 점수,300초 경기 종료에 눈에 띄는 오류가 없다.

득점이 없거나 패스·슛이 지나치게 드물면 기능 오류가 아니더라도 R0 공격 품질 개선 항목으로 기록한다. 문제가 보이면 `팀/선수 역할`, `대략적인 경기 시간`, `공과 선수의 상황`, `기대한 행동` 네 가지만 알려주면 재현과 수정 범위를 좁힐 수 있다. 최종 검토 때는 “R0 육안 합격” 또는 관찰한 문제를 알려주면 된다.

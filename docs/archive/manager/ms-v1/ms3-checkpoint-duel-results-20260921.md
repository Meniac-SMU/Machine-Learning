## 평가 계약

- 대진마다 이전 정책이 Red인 20경기와 Navy인 20경기를 실행했다.
- 한 대진은 총 40경기이며 세 대진 합계는 120경기다.
- 경기당 300초, time scale 10, seed offset `493001`을 공통으로 사용했다.
- 양 팀 모두 inference-only PPO이며 규칙형·fallback·Human 감독은 없다.
- `MNG_PolicyAssistMode.None`을 사용한다.
- raw/effective action 불일치, 강제 pass override, 직접 blocked-pass 판단 보상이 한 번이라도 있으면 무효다.

이 계약은 `MNG-MS3-CHECKPOINT-DUEL-v1`로 동결했다. 서로 다른 두 ONNX를 한 Player에 포함하고 실행 인자로 이전 정책의 진영을 교환하도록 전용 평가기를 만들었다.

## 판정

300k는 기존 R0-Full 최종 평가에서 score rate `0.875`로 가장 좋은 R0 상대 성능을 보였고, 초기 P0와의 직접 대전에서도 `0.55`로 앞섰다. 그러나 100k와 200k에 대한 직접 우세는 입증하지 못했다. 따라서 다음 두 문장을 구분한다.

- **MS3 파이프라인과 300k R0-Full 완료 gate는 통과했다.**
- **300k가 모든 self-play checkpoint보다 강한 최종 리그 챔피언이라는 주장은 실패했다.**

현재 300k 모델은 사전에 정한 R0-Full gate의 선택 모델로 유지한다. 이번 추가 평가만으로 100k나 200k를 새 최종 모델로 교체하지 않는다. 100k와 200k 사이의 직접 대전이 없고, R0-Full 절대 성능은 300k가 더 높기 때문이다. 이후 self-play 모델을 다시 승격할 때는 R0 평가와 함께 초기·중간·최신 checkpoint 풀을 상대로 한 소규모 리그 점수를 필수 선택 기준으로 추가하는 것이 적절하다.

# MS1 사용자 확인 체크리스트

자동 평가와 검수용 Player 빌드는 통과했다. 이 확인은 합격 gate를 다시 계산하는 절차가 아니라, 사람이 보았을 때 행동이 자연스럽고 패스 보조가 의도대로 보이는지 확인하는 짧은 검수다. 12초 headless smoke에서는 R0-Easy·1배속 bootstrap과 정책 명령을 확인했고 런타임 예외가 없었다.

## 실행 절차

1. `Builds\MNG_MS\MS1-Review\review-build-info.json`에서 `result`가 `Succeeded`, `errors`가 `0`, `timeScale`이 `1`인지 확인한다.
2. `Builds\MNG_MS\MS1-Review\MNG_MS1_Review.exe`를 실행한다.
3. 별도 조작 없이 **최소 12 episode, 권장 20 episode(약 6~10분)**를 본다. Scene은 공격과 수비/전환 fixture를 결정론적으로 번갈아 실행하고 1배속으로 계속 반복한다.
4. 아래 항목을 보면서 문제가 생긴 episode의 상황과 대략적인 시각을 메모한다. 한 번의 우연한 충돌보다 반복되는 패턴을 기준으로 판단한다.
5. 확인을 마치면 `Alt+F4`로 종료한다. 비정상 종료나 예외를 확인해야 할 때는 `C:\Users\USER\AppData\LocalLow\DefaultCompany\Turtle Agent\Player.log`를 본다.

- [ ] Red가 선택한 PPO, Navy가 느린 R0-Easy로 보인다.

- [ ] 같은 매니페스트의 모델 SHA-256이 `311f72b3d625d76156ba581ae060610b701d68bd8e69ff2a7b3afee8cc9b4e81`이다.

## 공격 행동

- [ ] Red가 공을 가진 공격 상황에서 대체로 상대 진영 쪽으로 전진한다.
- [ ] 슈팅 기회에서 유효 슛이나 득점 시도를 하며, 공 근처에서 반복 정지하거나 한 자리 회전만 하지 않는다.
- [ ] 전진 통로가 열려 있으면 불필요하게 패스만 반복하지 않는다.
- [ ] 전진 통로가 상대에게 막히면 후진하거나 옆으로 오래 끌기 전에 패스를 먼저 검토하는 장면이 보인다.

## 패스 행동

- [ ] 패스가 같은 팀 선수의 몸 정중앙만 계속 향하지 않는다.
- [ ] 좌우 중 경기장 중앙에 가까운 쪽으로 수신자보다 약간 비켜 찬다.
- [ ] 비켜 찬 공을 동료가 따라가 실제로 소유하거나 다음 플레이로 연결하는 장면이 보인다.
- [ ] 상대가 가로막은 상황에서 무리한 직선 드리블 충돌을 반복하지 않는다.
- [ ] 패스가 자책골 방향, 경기장 밖, 명백히 상대에게만 향하는 패턴으로 반복되지 않는다.

패스는 MS1의 보조 능력이다. 20 episode 안에서 항상 여러 번 성공할 필요는 없지만, 차단 상황에서 패스 선택과 중앙 쪽 오프셋이 한 번도 보이지 않거나 패스가 계속 자기 팀에게 도달하지 못하면 기록해 둔다.

## 수비·전환 행동

- [ ] 상대 소유 또는 중립 공으로 시작할 때 Red가 공을 회수하려고 압박한다.
- [ ] 회수 뒤 바로 공을 잃기만 하지 않고 짧게라도 소유를 유지하거나 공격으로 전환한다.
- [ ] 골문을 비우고 전원이 공 한 점에 겹치는 패턴이 반복되지 않는다.
- [ ] 수비 성공이 단순히 30초 동안 멈춰 기다린 결과처럼 보이지 않는다.

## 물리·안정성

- [ ] 같은 팀 선수들이 장시간 겹치거나 서로 밀어 움직이지 못하는 현상이 없다.

# MS2 사용자 확인 체크리스트

MS2 자동 gate는 통과했다. 이 체크리스트는 결과를 다시 합격시키기 위한 절차가 아니라, 최종 증거와 사람이 중요하게 보는 행동 경계를 빠르게 확인하기 위한 것이다.

- [ ] `Logs/MNG-MS/MS2-completion-20260920/ms2-completion.json`의 `status`가 `completed`다.
- [ ] 선택 후보가 `MNG_MS2-20260920-r002-step19912`다.

- [ ] 최종 비교의 `passed`가 `true`, `matchSeconds`가 `300`, `matchesPerTeamAndPolicy`가 `20`이다.

## 2. 핵심 경기 결과 확인

- [ ] ONNX 합산 score rate가 `0.525`로 `0.50` 이상이다.

- [ ] ONNX 40경기와 무작위 40경기의 개별 결과가 네 `Full-*.json`에 각각 20개씩 있다.

## 3. 강화학습 경계 확인

- [ ] 정책은 133개 관측과 여섯 팀 명령을 사용한다.
- [ ] 이동·드리블·패스 목표·슛·골키퍼는 공통 코드 기술층이 실행한다.

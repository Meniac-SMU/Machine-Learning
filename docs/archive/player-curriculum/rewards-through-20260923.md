## 지급 방식

보상은 팀 공동 보상과 개인 보상으로 구분한다.

| 구분 | 지급 방식 | 의미 |
| --- | --- | --- |
| 팀 그룹 보상 | 해당 팀의 `SimpleMultiAgentGroup`에 지급 | 팀원 4명이 공동으로 학습하는 신호 |
| 개인 보상·패널티 | 행동 선수에게 직접 지급 | Pass 송신자, 운반·드리블 성공자, 무의미하거나 위험한 Kick 선택자 |

HUD의 누적 보상은 다음 방식으로 계산한다.

- 팀 그룹 보상은 사건마다 한 번 기록
- Pass·운반·드리블 개인 보상과 행동 선택 패널티는 팀 장부에 별도로 합산
- 네 선수에게 전달되는 학습 신호를 단순히 네 배로 합산한 값이 아님
- 득점·실점과 경기 승패를 포함한 현재 경기의 장부 값
- 새 경기 시작 시 `0`으로 초기화

## 팀별 TensorBoard Reward 통계

`SoccerRewardEngine`은 실제 지급 보상을 Red와 Navy로 분리해 기록한다. Self-Play처럼 양 팀이 동시에 학습해도 서로 상쇄되지 않는다.

| TensorBoard 태그 | 집계 방식 | 의미 |
| --- | --- | --- |
| `Soccer/Red/Match Reward` | 경기별 평균 | 요약 구간에서 종료된 Red 경기 장부의 평균 |
| `Soccer/Navy/Match Reward` | 경기별 평균 | 요약 구간에서 종료된 Navy 경기 장부의 평균 |
| `Soccer/Red/Reward/Summary Total` | 합계 | 해당 Trainer 요약 구간에서 Red에 실제 지급된 보상 총합 |
| `Soccer/Navy/Reward/Summary Total` | 합계 | 해당 Trainer 요약 구간에서 Navy에 실제 지급된 보상 총합 |
| `Soccer/Red/Reward/{RewardKind}` | 사건별 합계 | Red의 득점·승패·Pass·수비·패널티 등 종류별 실제 지급 합계 |
| `Soccer/Navy/Reward/{RewardKind}` | 사건별 합계 | Navy의 득점·승패·Pass·수비·패널티 등 종류별 실제 지급 합계 |

`Match Reward`는 HUD와 같은 장부다. 팀 그룹 보상은 사건당 한 번, 개인 보상과 패널티는 해당 팀 장부에 한 번 합산하며 네 선수 수로 곱하지 않는다. 종료된 경기가 없는 요약 구간에는 `Match Reward`가 기록되지 않지만 `Summary Total`과 사건별 태그는 계속 기록된다.

기존 `Soccer/Reward/{RewardKind}`는 과거 Run과 Dashboard 호환을 위해 남겨 둔다. 이 태그는 두 팀 값이 합쳐져 득점 `+1/-1`이나 승패 `+0.5/-0.5`가 상쇄될 수 있으므로 팀 성능 추세 판단에 사용하지 않는다.

## 소유권과 Pass 확정

대부분의 보조 보상은 단순 접촉이 아니라 안정적인 공 제어를 전제로 한다.

### 소유권 확정

- 같은 팀의 마지막 접촉 상태 `0.75초` 유지
- 제어 선수가 공에서 `4m` 이내에 위치
- 전환 시도가 `2초` 동안 확정되지 않으면 중립 소유권 처리
- 경기 시작 후 최초 소유권에는 수비 회수나 압박 회수 보상 없음
- 공격 전진과 일반 운반 보상은 더 엄격하게 공과 `2.4m` 이내인 안정 제어만 인정
- `2.4m` 밖에 있던 시간은 안정 제어 시간이나 운반 후보 시간에 포함하지 않으며, `4m` 밖이면 carrier를 비움

### 패스 확정

- 서로 다른 같은 팀 선수 사이의 연결
- 패스 시작점과 수신점 거리 `3m` 이상
- 송신자 접촉 후 수신자 접촉까지 최소 `0.1초`
- 수신자가 마지막 접촉 상태를 추가로 `0.35초` 유지
- 확정 시점에 수신자가 공에서 `4m` 이내에 위치
- 확정 시 팀 그룹 일반 Pass 보상과 송신자 개인 Pass 보상을 함께 지급

## Dribble 판정

드리블 후보는 공을 제어하는 선수의 가장 가까운 상대가 `2.5m` 이내에 있을 때 시작한다. 다음 조건을 모두 만족해야 성공이다.

1. 후보 시작 후 최소 `0.5초`, 최대 `3초` 이내
2. 같은 선수가 마지막 공 접촉자이자 확정된 소유자
3. 선수가 공격 방향으로 `2m` 이상 전진
4. 공이 공격 방향으로 `1.5m` 이상 전진
5. 선수와 공의 거리 `4m` 이하
6. 선수가 처음 추적한 수비수보다 공격 방향 앞에 위치

성공 시 팀 보상과 개인 보상을 함께 지급한다. 같은 선수는 한 소유권에서 한 번만 드리블 보상을 받을 수 있다.

상한에 걸리지 않은 한 번의 드리블 성공이 HUD 팀 장부에 더하는 총값은 다음과 같다.

| 전술 | 팀 보상 | 개인 보상 | 장부 총증가 |
| --- | ---: | ---: | ---: |
| Base | `0.005` | `0.01` | `0.015` |
| Attack | `0.008` | `0.015` | `0.023` |
| Defense | `0.003` | `0.008` | `0.011` |
| Press | `0.005` | `0.01` | `0.015` |

## Controlled Carry 판정

상대가 바로 앞에 있지 않아도 공을 안정적으로 운반하는 기본기를 별도 사건으로 인정한다. 후보 시작 후 다음 조건을 모두 만족해야 한다.

1. 최소 `0.4초`, 최대 `4초` 안에 성공
2. 같은 선수가 확정 carrier이자 마지막 공 접촉자
3. 선수와 공이 모두 공격 방향으로 `2m` 이상 전진
4. 선수와 공의 거리 `2.4m` 이하
5. 명시적 Controlled/Strong Kick을 하면 현재 운반 후보 종료

성공 시 모든 전술에 팀 `0.0025`와 개인 `0.005`, 합계 `0.0075`를 지급한다. 같은 선수는 한 소유권에서 한 번만 받을 수 있고, 팀·개인 합산 운반 상한은 소유권당 `0.03`이다.

## Strong Kick과 자책골 안전 판정

Strong Kick은 다음 중 하나일 때만 의미 있는 선택이다.

- 자기 수비 깊이 `-20m` 이하에서 공격 방향 성분 `0.35`를 넘는 걷어내기
- `5~34m` 전방 lane 폭 `4.5m` 안에 동료가 있는 긴 Pass
- 공격 깊이 `+20m` 이상이며 상대 Goal plane까지 `24m` 안에서 골문을 교차하는 슛

그 외 Strong Kick은 개인 `-0.003` 패널티를 받는다. 자책골 안전 보정은 요청 방향만 보지 않고 `현재 공 속도 + Kick 힘 / 질량 × 0.02초`의 합성 속도를 사용한다. 자기 Goal plane을 향하거나 Goal 위험 지역에서 충분히 전진하지 않는 Kick은 중앙 Controlled Clearance로 바꾸고 개인 `-0.02`를 적용한다. 보정된 힘으로도 기존 골문 방향 속도를 이기지 못하면 그 X 속도 성분을 먼저 제거한다.

### Stadium 공통 판정

Base·Attack·Defense·Press·Rule은 모두 `SoccerArenaGeometry`의 실제 데모 골문 치수를 사용한다. Profile, 보상 크기·주기·거리 상한은 팀별 기존 계약을 유지하며 필드·골문 수치는 [경기 계약](../../soccer/gameplay-contract.md#활성-stadium-공통-scene)을 따른다.

| 항목 | 현재 공통값 |
| --- | --- |
| 득점 / 실점 | `+1 / -1` |
| Strong Kick / 위험 Kick 패널티 | `-0.003 / -0.02` |
| Controlled / Strong Kick 물리 힘 | `2000 / 5000` |
| 슛 예측 거리 / 자책골 예측 거리 | `24 / 36m` |
| 골문 궤적 기준 반폭 | 약 `10.196m` |
| 골문 위험 좌우 범위 | 실제 데모 반폭 + `4m` |
| 득점 사건 | 데모 프레임 제외, 골문 안쪽 영역·면과 공 중심 위치 확인 |

의미 있는 Strong Kick과 자책골 궤적은 환경의 Strong 힘 `5000`으로 예측하고, 중앙 안전 보정의 합성 속도 계산에는 Controlled 힘 `2000`을 사용한다. 모서리의 도달할 수 없는 목표점과 공의 최종 위치는 Stadium 경계 안으로 제한하되 보상의 거리·수치·주기·상한은 그대로다. Geometry와 Kick 변화는 사건 발생 빈도와 기존 ONNX 행동 품질을 바꿀 수 있으므로 재평가·재학습이 필요하다.

## 중첩과 배타 관계

### 함께 받을 수 있는 보상

- 전진 패스 성공: 일반 패스와 전진 패스 동시 지급
- 세 번째 선수가 연계를 완성한 전진 패스: 일반 패스, 전진 패스, 3인 연계 동시 지급 가능
- 협력 압박 성공: 빠른 압박 회수와 협력 압박 동시 지급
- 드리블 돌파 성공: 팀 드리블과 개인 드리블 동시 지급
- 안정 운반 성공: 팀 운반과 개인 운반 동시 지급
- 일반 패스 성공: 팀 일반 Pass와 송신자 개인 Pass 동시 지급
- 공격 전진·포메이션 개선: 다른 행동 보상과 같은 시점 또는 같은 소유권에 추가 지급 가능
- 동료 과밀 패널티: 소유권이나 다른 성공 보상과 무관하게 같은 샘플 시점에 함께 적용 가능

### 함께 받을 수 없는 보상

- 수비 회수와 빠른 압박 회수는 같은 소유권 전환에서 서로 배타적
- 빠른 압박 조건을 만족하면 수비 회수 대신 빠른 압박 회수 지급
- 협력 압박은 일반 수비 회수가 아니라 빠른 압박 회수에만 추가 가능

모든 양수 보조 보상의 합은 아래 전체 shaping 상한을 넘을 수 없다.

## Formation 구성

포메이션 보상은 미드필더와 스트라이커의 시작 위치 복귀나 고정 대형 유지를 요구하지 않는다. 어느 한 팀의 소유권이 확정된 동안 양 팀의 간격·지원·공수 균형 개선을 평가하고, 수비·골키퍼 겸임 선수만 공통 이동 규칙에 맞춘 후방 역할 점수를 사용한다.

| 구성 | 비중 | 평가 기준 |
| --- | ---: | --- |
| 선수 간격 | `30%` | 네 선수의 모든 쌍 평가. `5~34m`는 최대 점수, `1.5m` 이하 또는 `52m` 이상은 0점, 중간 구간은 선형 보간 |
| 지원 선택지 | `35%` | 소유 팀은 공 소유자, 비소유 팀은 공을 중심으로 `3~32m` 안의 선수 평가. 지원 선수 2명이면 최대 점수 |
| 공수 균형 | `25%` | 공 뒤 커버와 소유 시 전방 침투 선택지 평가. 소유 시 공보다 공격 방향 `2~34m` 앞 선수 인정 |
| 수비·골키퍼 겸임 역할 위치 | `10%` | 소유 시 하프라인 안쪽 지원선, 비소유 시 공이 수비 깊이 `-8m` 이하이면 적극 차단 목표, 아니면 시작 골문 깊이와의 거리 평가 |

수비·골키퍼 겸임 선수의 역할 점수 범위는 다음과 같다.

- 팀 소유 시 공격 깊이 `-4m` 이내는 최대 점수
- 공격 깊이 `-4~+4m` 구간은 선형 감소하고 `+4m`부터 0점
- 비소유 시 공이 수비 깊이 `-8m` 이하이면 공통 Keeper Engage 목표 깊이, 아니면 시작 골문 깊이와의 차이가 `6m` 이내일 때 최대 점수
- 해당 목표 깊이와의 차이 `6~30m` 구간은 선형 감소하고 `30m`부터 0점
- 역할 선수가 없으면 역할 위치 점수 `0.5`

이 역할 점수는 학습을 보조하는 양수 포메이션 shaping이다. 실제 이동 제한은 보상과 무관한 공통 action shield가 보장한다. Neural 정책, 모델 없는 fallback과 Rule 모두 공격 깊이 `-4m`부터 공격 방향 성분을 완만하게 줄이고 하프라인 `0m`에서 공격 방향 힘과 속도를 차단한다. 자기 진영 위협 공에는 `EngageBall`로 공과 Goal 사이를 적극 차단하고, 먼 상대 소유나 하프라인 초과에는 `RecoverGoal`로 복귀한다.

포메이션 점수는 `0~1` 범위다. `0.75초`마다 직전 점수와 비교하며 `0.08` 이상 좋아진 경우에만 `향상량×전술별 배율`을 지급한다. 점수가 나빠져도 FormationChange 자체의 음수 보상은 없다.

동료 과밀은 포메이션 개선과 별도 사건이다. 확정 소유권이 없어도 평가하며, 수평 거리 `3m` 이상은 `0`, `2m`는 심각도 `0.5`, `1m` 이하는 심각도 `1`이다. 이 절대 거리 패널티 덕분에 포메이션 점수의 변화가 작거나 개선 문턱에 못 미치는 한 쌍의 밀집도 직접 억제한다.

| 무의미한 Strong Kick | 행동 선수 개인 `-0.003`, 소유권당 최저 `-0.015` |
| 자책골 위험 Kick 보정 | 행동 선수 개인 `-0.02` |

무의미한 Strong Kick과 자책골 위험 Kick은 합산해 경기당 최저 `-0.1`의 행동 선택 패널티 상한을 사용한다.

현재 별도 패널티가 없는 행동은 다음과 같다.

- 시간 경과와 정지 상태
- 벽이나 선수 충돌
- 일반 공 접촉과 Dribble Push 자체
- Controlled Pass 실패와 정상 슛 실패
- 소유권 상실 자체
- 포메이션 점수 하락
- 무승부

보상이 없다는 것은 해당 행동이 항상 바람직하다는 뜻이 아니다. 득점·승패 목적과 양수 보조 보상의 기회비용을 통해 간접적으로 학습한다.

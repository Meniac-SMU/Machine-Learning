고정100경기 원인 계측은 거리실패89%, 킥실패7%, 다른접촉/다른carrier/시간초과0%, 안정0.1/0.2/0.35초 도달11%/9%/7%였다. 안정 기준을 낮춰도 병목이 남으므로0.35초를 유지한다. 안정 전 공이2.4m를 벗어나면 기술 추격이 수신 후 최대2초 안에 다시 접근할 기회를 주고, 이 시간에는 안정·전진 보상을 지급하지 않으며 안정 clock을0으로 되돌린다. 안정0.35초 이후 거리초과는 즉시 실패다. 성공 순간의 현재 확정수신자·2.4m·3m 전진 조건은 불변이다.

이 회복 수정의 승인r018/동일seed13579 고정100 비교는 성공2→8%, 안정수신7→11%, 평균전진0.19→0.51m, 거리실패89→27%였다. 회복 중 다른 선수 실제접촉62%는 무효로 끝났으며 성공에 포함하지 않았다. 성공 신호와 전진량이 함께 개선돼 새 r00432workers100k 한정학습을 허용하되, 학습5요약과 독립300경기의50%/85%/15초 기준은 완화하지 않는다.

r004100,412의 최근5요약은 성공6.67~8.99%, 안정수신11.24~15.00%로 평탄했고 고정100은 성공14%/안정18%/다른 선수 접촉 실패44%/거리실패30%였다. 안정에 도달하면 대부분3m를 완료하므로 전진 보상을 늘리지 않는다. 지정 수신자 외 Red 동료를 안정0.35초까지 멈춘 수신 격리는 고정100에서97회/90.88초 개입했지만 성공9%/안정16%로 악화되어 제거했다. 보상 감사에서 안정 전에도 전진 high-water와 shaping을 지급하던 순서 문제가 확인됐다. 다음 단일 변경은 안정0.35초가 확정된 뒤에만 전진량과 상한0.15 shaping을 갱신한다. 보상액·성공3m/6초·접촉실패는 불변이며 검증 뒤 r004 최종모델에서 r00532workers100k 한정학습으로 효과를 확인한다.

r005100,132는 최근5요약 성공8.96~22.39%, 안정14.93~31.34%로 r004의 평탄한6.67~8.99%보다 개선됐고 같은seed 고정100도14→23%였다. 동일 optimizer에서 상승이 재현됐으므로 init_path 없는 resume YAML로 같은 r005를 총200k까지만 연장한다. 설정·보상·32workers는 불변이며 200k에서도 각50%/85% 연속 기준과 고정평가가 열리지 않으면 추가 단순연장은 금지한다.

r005200,064의 최근5요약 성공22.37~35.48%, 안정34.21~45.16%이며 고정100은149,876 checkpoint33%, 최종29%다. 단순연장은 중지한다. 안정된 에피소드의 약70~80%가 완료되지만 안정 자체가50% 미만이고, 엄격 인계 보상과 전진 shaping 사이에 안정0.35초 달성 신호가 없었다. 다음 단일 보상은 같은 지정 수신자가 마지막 접촉자·공2.4m 이내로 실제0.35초를 최초 충족할 때 개인0.1을 지급한다. null carrier/거리 밖/우연접촉은 제외하고 라운드1회이며 기존 cap0.15 전진과0.4+0.1 완료는 유지한다.

## 사전 감사

- 기존 커리큘럼 모드는 포메이션·군집만 억제했다. r009 실제 이벤트에는 `ControlledCarry`, `PassSuccess`, `PassIndividual`, `AttackSuccess`, `WastefulStrongKick`이 섞였다.
- 이제 `ApplyGroupReward`, `ApplyExplicitIndividualReward`, `AwardBehaviorPenalty` 모두 레슨별 허용 목록을 검사한다. 일반 경기용 Profile은 삭제하거나 0으로 덮어쓰지 않는다.
- 설치된 POCA의 `reward_buffer`는 개인 reward이고 그룹 reward는 별도 누적이다. 이전 YAML의 `measure: reward` 0.32가 그룹 성공률 80%를 의미한다는 해석은 잘못됐다. 고정 phase YAML + 실제 성공 지표 평가 후 새 Run 초기화로 바꾼다.
- 운반 보상 합계가 재소유 때 초기화되던 문제를 에피소드 cap으로 수정한다.
- 인위적인 4m 무슛 종료선은 사용하지 않는다. 명시적 슛 없이 난 골은 여전히 실패다.
- 성공은 마지막 유효 슛의 8초 이내이며 플레이트 초기 접촉 뒤 선수 재접촉 없이 난 골만 인정한다. 한 번의 킥 뒤 다시 밀어서 득점하는 과대평가를 막는다.
- L1만 안정 carrier이며 공 1.8m 이내일 때 킥을 허용한다. 공 밖에서 플레이트 주기를 소비하지 않도록 하는 학습 보조 조건이며, 물리 힘과 일반 경기 행동은 바꾸지 않는다. 개선 효과는 실험으로 확인한다.

## 허용 목록

| 단계 | 개인 shaping | 성공 그룹 보상 | 차단 |
| --- | --- | --- | --- |
| L0 | 접근, 안정 소유 | 0.4 | 모든 일반 전술/다른 레슨 보상 |
| L1 근거리 | 소유, 실제 킥 접촉, 방향 슛, 득점, 작은 지원 간격 | 0.4 | 일반 운반·공격·패스·압박·수비·포메이션·기존 패널티·커리큘럼 운반 |

골키퍼 이동 shield와 자책골 방향 안전 보정은 계속 강제한다. 지원자 최소 간격 6m와 서로 5m 조건도 유지한다. 보상 변경 수치의 단일 기준은 [보상 기준표](../../soccer/rewards.md)다.

## 단계·승급

1. r010은 r007에서 초기화해 `ShortRangeFinish`를 학습한다. Navy 비활성, 슈터는 골문 20~24m 앞. 50k마다 저장하고 100k 진단 후 개선 중이면 먼저 1m까지 유지한다. 고정 100경기 평가가 300k 26% → 500k 45% → 750k 56% → 1m 45%다. 상승 후 변동이 있어 `curriculum_l1_extended_poca.yaml`과 `--resume`으로 우선 총 1.5m까지 한정 연장한다. 보상·환경·optimizer는 그대로이고 max_steps와 보존 체크포인트 수만 다르다. 1.5m 평가에서는 300경기로 표본을 늘려 정체와 변동을 구분한다. 이후 개선 중일 때만 0.5m 단위로 총 3m 이내 연장하고, 정체라면 슛 조준/마무리 원인을 분리한 새 실험을 설계한다. 승급 기준을 통과하면 그보다 먼저 평가해 다음 phase로 이동할 수 있다.
2. 근거리: 최근 5개 10k 요약 각각 성공 75% 이상(기존 80%, -5%p), 소유/유효 슛 85%, 평균 20초 이하, 일반 보상 누출 0.
3. 통과 체크포인트 보존 후 `curriculum_l1_carry_poca.yaml`로 새 Run을 초기화한다. 최종 8m 제어 운반→명시적 킥→실제 득점은 유지한다.
4. 최종 L1: 5개 연속 요약 성공 65% 이상(기존 70%, -5%p), 소유/유효 슛 85%, 방향 슛 75%, 평균 20초 이하. 고정 신경망 별도 평가와 L0 소유 85% 회귀 확인 후 L2로 진행한다.
5. L2는 승인된 L1 모델에서 초기화한다. 고정된 짧은 거리에서 시작해 무작위 배치로 확대한다. 명시적 킥으로 3m 이상 패스 후 더 유리한 팀원이 0.75초 안정 소유해야 성공한다. 발신·수신 모두 Neural. 최신 완화 기준은 위 L2 실행 기준의 성공 50%, 소유 85%, 평균 15초 이하 및 별도 평가다.

## 성능·중단

- 2026-09-04 재개: r014는 소유/킥 시도보다 첫 슛 방향과 재시도 방향이 병목이었다. 같은 보상으로 Run 번호만 늘리지 않고 공통 Neural 근거리 슈팅 기술층을 먼저 구현·고정 평가한다. 확정 소유·공 1.8m·골문 18m 안에서만 골문 궤적 킥을 권장하고 빗나갈 킥을 보류한다. 효과가 확인되면 r014 500,136 checkpoint에서 새 Run 하나를 초기화하고 코드 개입 빈도와 실제 성공을 함께 추적한다. 최종 성과에 코드 기술이 포함됨을 명시한다.

- r014는 r013의 연속 기준 및 중간 고정 평가를 통과한 149,876 checkpoint에서 초기화해 원래 배치(난이도 1)로 복귀한다. `curriculum_l1_full_poca.yaml`, 재개용 `curriculum_l1_full_resume_poca.yaml`; 최대 500k/100k 진단/50k 저장/16 workers. 보상·물리·75% 성공 기준 불변. 과거 고정 평가 seed 24680은 모델 선택에 사용했으므로 원래 배치 최종 승급은 새 seed 13579의 300회와 최근 5요약을 함께 확인한다. 근거리 승급을 확인한 뒤에만 8m 운반→슛→득점 phase 2로 진행한다.

- r013은 정면 과제의 최근 5요약 및 고정 평가 통과 후 중간 각도(0.5)로 확장한다. r012 최종 500,008 checkpoint에서 초기화하고 `curriculum_l1_angle_poca.yaml`로 최대 200k/100k 진단/50k 저장/16 workers의 짧은 보강을 수행한다. 보상·물리·신경망 설정 불변. 재개는 init_path 없는 `curriculum_l1_angle_resume_poca.yaml`. 종료 후 중간/원래 배치 고정 300회 평가로 판단하며, 중간 과제 성적만으로 운반 단계나 L2에 승급하지 않는다.

- r012 가설은 보상 추가가 아닌 슛 시작 배치의 단계화다. `soccer_l1_spawn_difficulty` 기본값 1은 기존 좌우 ±1.5m를 유지한다. 근거리 phase에서만 0(정면) → 0.5(±0.75m) → 1(±1.5m)로 확대한다. 슈터의 골문 거리 20~24m와 좌우 ±4m, 공 전방 거리 1~3m, 물리, 소유, 명시적 슛/득점 판정은 불변이다. 최종 운반 phase는 매개변수와 무관하게 항상 난이도 1을 강제한다.
- r012는 r011 최종 500,388 checkpoint에서 초기화하여 난이도 0, 16 workers, 최대 500k/50k 저장/100k 진단으로 시작한다. 조준 보상 parameter 1을 포함해 보상 수치는 r011 그대로다. 같은 모델을 쉬운 배치와 원래 배치로 각각 사전 평가한 후 학습한다. 쉬운 배치의 성공 상승은 학습 개선으로 보고하지 않는다.
- 준비 단계도 최근 5요약 성공 75%, 소유/유효 슛 85%, 평균 20초 이하를 요구한다. `subtask_gate_passed`는 다음 배치 확대 후보만 뜻한다. `training_gate_passed`는 난이도 1의 동일 5요약 + 고정 평가가 필요하다. 난이도를 확대할 때 새 Run/YAML로 보존한다. 준비 단계가 500k에도 정체되면 첫 슛 각도·거리·힘·방향 진단으로 원인을 재검토하고 맹목 연장하지 않는다.

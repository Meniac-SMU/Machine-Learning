## 판단 및 다음 실험 설계

- 두 조건 모두50% 미만. L2 완료/L3 진입 금지, 수신 성공 기준 추가완화 없음.
- 단순 방향gate는 가능한 킥 방향만 제한하고 계속 전진하는 선택을 해결하지 않는다. 기회가 남아 있을 때 이동을 조절하고 방향을 준비하는 학습 신호가 필요하다.
- 기존 준비보상은 첫 자세 품질을 무지급 기준선으로 삼고 더 좋아진 부분에만 주므로, 이미 괜찮은 방향에서 계속 전진해 기회를 망치는 선택에 직접 불이익이 없다. 이것은 코드 감사 결과이며 보상 원인 단독 확정은 아니다.
- 다음 보상 실험은 **처음 유효했던 고정 대상의 기회를 자기 전진으로 잃는 사건**의 제한된 1회 불이익과 실제 적합한 킥의 보상 균형을 우선 검토한다. 단순 소유소실/대상 이동/무효 수치를 오판해 벌주지 않도록 조건을 분리하고 정지로 보상을 쌓지 못하게 한다. 정확한 수치는 코드/보상표/테스트에 함께 확정한 뒤 실행한다. 이번 감사에서 실제 불이익/자동감속/자동조준/자동킥은 추가하지 않았다.
- 초기 정책의 L1 운반 습관과의 충돌 가능성이 있으므로 같은 진단 Player/protocol2/seed86420으로 승인r017과 r007의 L1 phase2 각300경기 회귀를 검증한다. 결과 확인 전 기존 L1 능력이 유지된다고 주장하지 않는다. 이미 준비된 r007을 무조건 연장하거나 r008을 생성하지 않는다.

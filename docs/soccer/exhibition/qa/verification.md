# 전시 UI 디자인 v6 검증 기록

검토일: 2026-09-26. 일시 정지 동작은 HTML 디자인 미리보기에만 추가했다. Unity Scene·Runtime·입력·모델·물리·학습·빌드는 변경하지 않았다.

이전 자료: [v5 검증 기록](../../../archive/exhibition/verification-v5-20260926.md). 기존 캡처와 검증 파일은 보존했다.

## 브라우저 확인

1600×1020 viewport의 인앱 브라우저에서 한국어와 영어를 확인했다. [검사 수치](manager-v6-checks.json).

| 변경 | 확인 결과 |
|---|---|
| Esc 정지 화면 | 경기 중 Esc로 반투명 흰색 배경과 중앙 하이드레이션 브레이크! / Hydration Break! 표시 |

| 모델명 아래 여백 | 이름을 한 줄로 고정하고 빈 두 번째 줄 제거. v5 대비 한국어 높이 27%, 영어 높이 20% 축소 |
| 기타 언어별 여백 | 한국어 조작 안내, 팀 배지, 뒤로·모드·가이드 버튼 폭과 모델 모달 높이를 별도 축소 |
| 같은 언어 안의 크기 | 한국어 점수 0→12 변경, 영어 판단·보상 변경 시 측정 HUD 폭·높이 동일 |
| 중앙 탭 | 한국어 모달 중앙 x=800, 두 탭 묶음 중앙 x≈800. 두 언어 모두 중앙 정렬 CSS 적용 |
| 모델 선택창 | 한국어 모달 26cqw, 영어 28cqw 고정 높이. 목록 제목·설명 넘침 없음 |

| 로그 | 확인 시 브라우저 error/warn 0개 |

언어를 바꾸면 해당 언어의 고정 레이아웃으로 크기가 바뀐다. 같은 언어 안의 문자열 변화에는 배경 크기가 변하지 않는 원칙을 유지한다. v5의 한영 동일 크기 계약은 이번 요청에 따라 대체했다.

## 후속 수정: 경기 재개 / AI 시뮬레이션 2배속

- 정지 화면의 한국어 버튼을 `경기 재개`로 변경했다. 영어는 `Resume match` 유지. [최신 캡처](manager-v6-resume-simulation.png).
- 직접 플레이 모드 1배속, AI 시뮬레이션 모드 2배속. 경기 시계와 이를 기준으로 하는 예시 판단·보상 갱신에 적용한다. H 조작 전환은 게임 모드 배율을 변경하지 않는다.
- 브라우저에서 AI 시뮬레이션 선택·시작, 2배속 검토 안내, 정지 화면과 변경된 버튼 및 정지 시간 유지 확인. 브라우저의 백그라운드/검토 세션 시간 진행과 호스트 벽시계가 달라 실제 배율의 수치 검증은 아래 제어 시간 검사로 구분했다.
- [제어 시간 검사](simulation-speed-checks.json): 시안 소스의 실제 타이머·재개 함수 본문을 Node VM에서 실행했다. 5초 경과 시 직접 플레이 5초, 시뮬레이션 10초 감소. 60초 정지 중 변화 없음. 재개 후 5초 경과 시 다시 10초 감소. 시뮬레이션의 300초 경기는 150초 경과 입력에서 종료 상태로 전환. 모두 통과.
- JavaScript 구문 검사 통과. Unity 실제 경기 배속은 구현하지 않았다.

## 후속 수정: 배속 배지 / 상단 정지 화면

- 시뮬레이션에서 시간 바로 오른쪽에 `2배속` / `2× SPEED` 표시. 직접 플레이에서 숨김 확인. 배경 rgb(202,42,62), 글자 rgb(255,255,255), 시간과 배지 사이 간격 약 0px 확인. 고정 폭은 한국어 5.8cqw, 영어 8.1cqw.
- 정지 배경은 요청의 투명도 90%를 문자 그대로 적용했다. computed background rgba(255,255,255,0.1), 즉 흰색 불투명도 10%. 기존 blur 2px 유지.
- 제목은 한국어 5.2→4.65cqw, 영어 5.6→5cqw로 약 10% 축소. 제목·버튼 묶음은 게임 영역 상단 20% 지점에서 시작. 화면 높이 405px에서 상단 차이 81px 확인.
- 두 언어 화면 및 브라우저 오류 0개 확인. JavaScript 구문 검사 통과. 번역 키 72개, HTML id 77개.

## 2026-09-27 일시 정지 시각 수정

블러 완전 제거, 흰색 투명도 93%(불투명도 7%), 제목·버튼 묶음의 시작 위치를 상단 20%에서 12%로 이동했다. 브라우저에서 backdrop-filter: none, rgba(255,255,255,0.07), 상단 위치 비율 약 0.12를 확인했다. 한국어·영어 공통 스타일에 적용했다. [최신 캡처](manager-pause-no-blur-20260927.png). Unity 변경 없음.

## 2026-09-27 일시 정지 제목·버튼 분리 배치

제목 색상 #F7F8F2, 상단 7% 위치 적용. 초록색 가로선 요소 제거. 버튼 두 개는 하단 중앙, 하단 여백 4%로 이동. 브라우저 computed 색상 rgb(247,248,242), 제목 상단 비율 약 0.07, 버튼 하단 비율 약 0.04, 중앙 오차 약 0px, 가로선 요소 0개 확인. 공통 스타일로 한국어·영어에 적용. 투명도 93%와 블러 없음 유지. [최신 캡처](manager-pause-white-bottom-20260927.png).

## 2026-09-27 배경 투명도 85%

일시 정지 배경을 투명도 85%(흰색 불투명도 15%)로 변경. 브라우저 rgba(255,255,255,0.15), backdrop-filter none 확인. 제목·버튼 배치 유지. [캡처](manager-pause-transparency85.png).

# 전시 조작·카메라·골키퍼 통계 수정

2026-09-27 사용자 후속 요청. UI 1차 최종본 위에서 실제 Unity 기능과 Windows Player를 수정한다. 이전 완료 기록은 `revision-20260927.md`에 보존한다.

## 변경과 판단

- H로 시점 전환 시 위치·회전·화각을 0.8초 smoothstep으로 전환한다. 도중에 다시 H를 눌러도 현재 화면 위치에서 반대쪽으로 이어간다. 실시간 기준으로 전환해 경기 배속의 영향을 받지 않으며 일시정지 중에는 카메라 이동을 멈춘다.
- RED 공격수 머리 표식은 몸통 렌더러의 실제 상단 경계에 붙이고 0.005m 안쪽으로 겹친다. 표식 자체의 크기·색은 유지한다.
- 전시 프리팹에만 선수 8명과 공의 Rigidbody Interpolate를 설정한다. 사람·감독·시뮬레이션 모두 화면에 보이는 경기가 부드러워야 하므로 전시 전체에 적용한다. 물리 업데이트 빈도·solver·신경망 결정 빈도는 변경하지 않는다. 학습용 프리팹·씬에는 보간이나 통계 컴포넌트를 넣지 않는다.
- 보간은 이전 물리 상태 사이의 표시 위치를 계산하므로 CPU 작업이 전혀 없는 것은 아니다. 대상 9개에 한정하고 별도 프레임별 메모리 할당이나 추가 물리 시뮬레이션을 만들지 않는다. 전용 CPU 프로파일링 결과로 주장하지 않는다. Unity Interpolate의 약 한 물리 틱(기존 0.02초) 표시 지연은 존재한다.
- Hydration Break 제목 `#14532D`, 배속 배경 `#FFE6E9`. 한국어·영어 같은 공통 화면 경로에 적용한다.
- 과거 `SoccerGoalOcclusionFader`의 URP 투명 재질 설정을 재사용한다. 현재 MNG 골대는 과거 이름과 다르므로 `redGoal`/`navyGoal` 태그의 렌더러를 사용한다. 전시 전용 재질을 한 번 생성하고 alpha 0.25를 유지한다. 매 프레임 가변 페이드는 제거한다. 콜라이더와 득점 판정은 그대로다.
- 골키퍼 몸통만 RED `#F18FAE`, NAVY `#86CFFA`로 교체한다. 원본 팀 재질은 수정하지 않는다.
- `ExhibitionKeeperTouches`는 공의 실제 충돌 콜백에서 골키퍼 몸통·킥 플레이트 접촉을 관측한다. 지속 접촉과 같은 물리 틱의 복합 콜라이더 접촉은 1회, 분리 후 재접촉은 새 1회다. 일반 선수 접촉과 비활성 경기 접촉은 제외한다. 골·킥오프 이후 누적을 보존하고 새 경기에서 초기화한다. 상황판의 선방/Saves 행에 양 팀 정수를 표시한다. 슈팅을 막은 경우로 한정하지 않는 사용자 지정 정의다.

## 사람/AI 물리 비교

|항목|기존 사람|AI|수정 후 사람|

|가속도|30m/s²|30m/s²|같음|
|감속도|45m/s²|45m/s²|같음|
|회전 속도|125°/s|125°/s|같음|

사람 패스는 기존 30m 전방 조준을 유지하므로 변경 후 34.6667m/s를 요청한다. 상대 위치에 따른 자동 조준은 추가하지 않는다. AI는 목표 도착·전술적인 저속 이동 때문에 실제 이동 요청이 최대치보다 작을 수 있지만 물리적 최대 속도와 가속 능력은 같다. 사람의 회전 입력은 보간된 Transform 대신 Rigidbody 회전을 사용한다.

패스와 슈팅이 같은 출구 속도일 수 있으므로 사람 슈팅 집계는 속도 비교 대신 실제 킥을 성공적으로 준비한 E/Space 의도로 구분한다. AI 보상 이벤트의 `Unspecified` 계약은 유지하며 E는 전체/사람 슈팅에 포함하지 않는다.

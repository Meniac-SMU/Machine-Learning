# 전시 빌드 후속 수정 · 2026-09-27

사용자 요청 10개 항목을 UI 1차 최종본 위에 적용한다. 기존 동결 시안·모델·빌드·검증 기록은 보존한다.

## 변경
- GOAL: 화면 아래에서 75% 높이(위에서 25%, 띠 중심), 전체 폭, 배경 투명도 30%(alpha 0.70).
- 시뮬레이션 배속: 중앙 상단, 흰색 배경과 빨간 글자. 기준 글자 크기 19 → 28.
- 직접 플레이: 경기 시작 시 AI 소유. H로 사람/AI 소유권과 추적/중계 카메라 전환.
- 조작 안내: AI 상태에는 H만, 사람 상태에는 이동·회전·패스·슈팅과 AI 전환 안내. 시뮬레이션에는 조작 안내 없음.
- 중계 카메라: 원본 경기장 위치 배율 0.94 → 0.88. 사람 추적 카메라 컴포넌트 보존.
- 일시정지 제목: 연두색 `#B9F54E`. 기존 위치·버튼·흰색 배경 투명도 85% 유지.
- 좌우 하단 HUD: 1.12배 확대. 한국어/영어 각각의 고정 폭, 우측·하단 여백 유지. 조작 안내는 AI/사람 상태별 사전 지정 높이를 사용하고 문자열 길이에는 크기가 변하지 않음.
- 영어 동일 반영. H 문구는 `Switch to human control` / `Switch to AI`.

## 입력 오류 수정
1. 전시 Builder가 `MNG_SpectatorCamera`를 제거하여 사람 모드 추적 시점이 사라졌다. 원래 컴포넌트와 연결을 유지한다.
2. `MNG_PlayerSkillExecutor.UpdateLifetimeV2`가 사람 모드에서도 매 물리 프레임 킥 플레이트를 초기화했다. AI 작업 취소는 유지하면서 사람의 플레이트 동작을 덮어쓰지 않는다. 비활성 경기 상태에서는 계속 초기화한다.
3. 사람 입력과 공 충돌 처리 모두 AI의 carrier lease를 요구했다. 사람 입력은 기존 쿨다운 조건 아래 플레이트를 직접 작동시키며, 실제 물리 접촉만 공 타격으로 이어진다. 사람의 실제 타격 시 기존 carrier가 있으면 해제한다. AI의 소유 판정은 그대로 유지한다. 경기 비활성 중에는 이동·킥 입력을 적용하지 않는다.

신경망·감독 AI 결정·보상/관측/행동 계약은 변경하지 않는다. 사람 슈팅은 실제 strong strike만 집계하고 패스는 제외한다.

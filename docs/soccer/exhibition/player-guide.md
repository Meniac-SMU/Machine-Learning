# MANAGER · 전시용 Player 사용 안내

이 문서는 UI 1차 최종본에 따른 Windows 전시 빌드의 사용법이다. 실행 파일의 최종 경로와 검증 결과는 `implementation-status.md`에서 확인한다.

## 실행 및 경기
1. 빌드 폴더의 `MANAGER.exe`를 실행한다. 함께 생성된 `MANAGER_Data`, DLL과 런타임 폴더를 함께 보존한다.
2. Unity 로고 없이 MENIAC 개발팀 로고를 표시한 뒤 한국어 시작 화면이 나온다. `Language`에서 한국어/영어를 선택한다.
3. `경기 준비`에서 양 팀 모델, 직접 플레이/AI 시뮬레이션, 5분/10분을 설정한다.
4. 직접 플레이는 1배속이며 **처음에는 AI 모드로 시작**한다. `H`를 누르면 RED 공격수를 직접 조작하고 공격수 추적 카메라로 전환된다. 다시 `H`를 누르면 AI와 중계 시점으로 돌아간다.
5. AI 시뮬레이션은 양 팀 모두 AI로 2배속이며 화면 중앙 상단에 매우 연한 빨강 배경·빨간 글씨로 배속이 표시된다.
6. 시작 화면 하단의 **종료하기 / Quit game** 버튼을 누르면 게임 프로그램을 종료한다. 경기 중의 `경기 종료`는 시작 화면으로 돌아가는 버튼이다.

## 키
|키|기능|
|---|---|
|W / S|전진 / 후진|
|A / D|회전|
|E|패스|
|Space|슈팅|
|H|RED 공격수의 사람/AI 제어 전환 (직접 플레이 모드만)|
|Esc|경기 일시정지/재개, 가이드·제작자·모델 목록 닫기|
|Enter|가이드 다음 장|
|Alt+F4|Windows Player 종료|

직접 플레이의 AI 상태에서는 `H: 사람 모드로 전환`만 안내한다. 사람 상태에서는 이동·회전·패스·슈팅과 `H: AI 전환`을 안내한다. 영어 UI도 같은 방식이다. 시뮬레이션에는 사람 조작 안내가 표시되지 않는다.

패스와 슈팅은 공격수 앞 킥 플레이트가 **실제 공에 닿을 때** 발동한다. 공과 떨어진 상태에서 키를 눌러도 원격 타격하지 않으며 타격 후 기존 쿨다운을 적용한다.

사람/AI 전환 시 카메라는 약 0.8초 동안 이동한다. 전시 모드에서는 선수 8명과 공의 화면상 움직임을 보간하며, 학습용 프리팹은 변경하지 않는다. 사람과 AI의 이동 요청 상한은 9m/s, 모터 가속도 설정은 30m/s²이며 물리 감쇠·마찰은 양쪽에 동일하게 적용된다. 패스는 같은 거리별 세기 계산을 사용하고, 수동 패스의 기존 30m 전방 조준에서는 34.67m/s를 요청한다. 슈팅도 AI와 같은 34.67m/s이며 실제 접촉과 충돌 상황에 따라 공의 관측 속도는 달라질 수 있다.

일시정지 화면의 `경기 재개`는 현재 경기를 이어가며, `경기 종료`는 시작 화면으로 돌아간다. 정규 시간이 끝나면 상황판이 유지되며 `종료`를 눌러 시작 화면으로 돌아간다.

## 모델과 상황판
- 신경망 6개: 초기 모델, 40만, 80만, 120만, 160만, 200만. 영어 표기는 Initial model, 400K, 800K, 1.2M, 1.6M, 2M이다.
- 규칙형 감독 4개: Recover, Balanced, Carry & Shoot, Random. 한국어에서는 한국어 설명을 병기한다.
- 신경망의 실제 step은 모델 목록에서 확인한다. 초기 모델도 사전 학습을 이어받은 모델이다.
- 상황판 순서: 최종 누적 보상 → 전체 슈팅 → AI/사람 슈팅 → 공 회수 → 선방.
- 슈팅 횟수는 실제 공 타격을 집계한다. 전체 슈팅은 AI 슈팅과 사람 슈팅의 합이며, 같은 세기의 패스도 슈팅으로 집계하지 않는다.
- 선방은 **골키퍼가 공에 접촉한 횟수**다. 몸통·킥 플레이트 접촉을 모두 포함한다. 계속 붙어 있는 접촉은 1회이며 떨어진 뒤 다시 닿으면 추가한다. 득점 후에도 누적되고 새 경기에서 초기화한다. 학습용 신경망 관측이나 보상은 추가하지 않는다.
- 골키퍼 몸통은 RED가 분홍색, NAVY가 하늘색이다. 골대는 항상 반투명이며 골대의 충돌 판정은 유지한다.
- MANAGER 이름과 팀 로고·제작자 이미지는 승인된 임시 자산이다.

## 가이드 및 화면
- 가이드는 한국어/영어 각각 5페이지다. 1: RED 팀 소개, 2: AI 감독의 6가지 전략, 3: 선수의 12가지 행동, 4: 조작키, 5: AI 시뮬레이션 안내. Enter로 다음 장을 열고 마지막 장에서 종료한다. Esc는 어느 장에서든 닫는다.
- 감독의 선택: 전진 운반, 패스 전개, 슈팅 시도, 적극 회수, 균형 유지, 후방 보호. 선수 행동은 현재 감독 전략과 상황에 따라 실행된다.
- 일시정지 제목은 흰색에 가까운 하늘색이며 테두리가 없다. 제목에만 짙은 남색 사각형 배경(투명도 5%)을 적용한다. GOAL 배경 투명도는 8%, 양쪽 골대 투명도는 40%다.
- 양쪽 골키퍼 킥 플레이트는 동일한 형광 노랑이다. 시작 화면 종료 버튼은 테두리 없는 연한 회색 글씨이며 경기 준비 버튼의 오른쪽 가장자리에 정렬된다.

## 재빌드
프로젝트 루트에서 `Tools/Build-Exhibition.ps1`을 실행한다. 새 빌드마다 별도 폴더와 생성 기록을 남긴다. Editor가 프로젝트를 사용 중이면 닫은 뒤 실행한다.

자동 Player 검증은 `MANAGER.exe -exhibition-smoke -exhibitionEvidence <프로젝트 내 출력 폴더>`를 사용한다. 이 옵션은 테스트 후 Player를 종료한다. 전시 실행에는 넣지 않는다.

# 5대5 감독 학습 연결

최신 선수 실행은 **attack-keeper-v1**, 규칙형 식별자는 **strong-v11**이다. T1 속공 전개에서 비소유 필드 2명이 전방 지원하고, GK 최고속도는 일반 선수의 1.2배이며 페널티 에어리어까지 활동한다. 소유 중 회전은 기존 대비 20% 감소, 드리블 감속은 10%p, 체력 회복량과 허용 이동 속도는 2배다. 감독 선택 코드·676관측/8행동·R1+M2는 유지하며 추가 학습은 하지 않았다. 일반 PlayMode는 최신 결과를 검사명별로 합쳐 103/104 통과다. 기존 컷백 장면의 수신·슛 기준 1건은 상대 가로채기로 미통과이며 실패 자료를 보존한다. EditMode 27개·strong-v11 정식 300초 경기 1개는 통과했고, 실제 렌더 300초와 기존 P9 모델 양 진영 300초 두 경기의 정상 종료도 확인했다. [속공 지원과 골키퍼 활동 범위](../../../../docs/soccer/rebuild-5v5/33_속공지원과_골키퍼활동범위.md)를 따른다. 아래 strong-v7 성적은 변경 전 이력이다.

P8 계약은 `MNG5-OBS676-A8-R1-M2-v2`, BehaviorName은 `MNG5_Manager_v2`다. 현재와0.25/0.50/0.75초 전의168개 공개/자기 팀 상태, 유효 플래그4개를 합쳐676개를 전달한다. 이산 행동은8개 중 하나, 기본 판단 주기는3초다.

보상은 자기 득점+1·실점−1·그 외0·종료 추가0이다. P7에는 Agent 보상 연결이 없었으며 새 학습 연결부에만 추가했다. 먼저 시험했던168관측 후보와 보상액 차이는0이다. 감독은 득실점 결과로 학습할 수 있지만 P8에서는 optimizer나 학습을 실행하지 않는다.

`FiveLearningSession`이 경기와 에피소드 리셋을 소유한다. 각 Agent는 공유 경기를 초기화하지 않는다. 이력은 경기/득점 재개/외부 초기화 때 지우고, 득점 ledger는 경기/외부 초기화에서만 새로 시작한다. Python 연결이 없으면 명시적인 규칙형 heuristic으로 실행된다. 기존4대4 모델과168관측 후보 모델은 호환되지 않는다.
